# Wave-Function-in-Quantum-Mechanics
Plotting and solution of the wave function for a particle in a potential well.

The technique used in this project to numerically solve the time-dependent Schrödinger equation is the Crank-Nicolson method, which is based on the Cayley approximation for the time-evolution operator.

Computations are performed for the eigenfunctions using the simplest possible interaction Hamiltonian: that of a potential well.

The goal is to calculate the solutions to this equation to obtain the wave function, distinguishing between its real and imaginary parts. 

Furthermore, the project verifies the conservation of
- Mean energy within an approximation error
- Analyzes probability oscillations across the quantum well
- Tracks how the probability distribution evolves as the particle changes its position over time.
